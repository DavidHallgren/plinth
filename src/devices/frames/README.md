# Device frame assets

These portrait PNGs are official Apple device-frame assets supplied for use in Plinth. Each file has a transparent display aperture sized to the corresponding screenshot resolution:

- iPhone 17 Pro Max: 1470 × 3000 frame with a 1320 × 2868 aperture
- iPhone 17 Pro and iPhone 17: 1350 × 2760 frame with a 1206 × 2622 aperture
- iPhone Air: 1380 × 2880 frame with a 1260 × 2736 aperture

Plinth draws the project screenshot beneath the selected frame in the shared `SceneRenderer`. Only portrait frames are bundled; landscape compositions can rotate the editable device element without storing another frame reference in project JSON.
